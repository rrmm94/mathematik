# UI-Vorschau: Mathematik-Prüfungstrainer im Stil der 3D-Druck Werkstatt

Vorher-Nachher-Bilder der wichtigsten Seiten (links aktuell, rechts neu). `00-vorbild-…` zeigt die Kopfleiste der 3D-Druck-Seite als Vorbild.

Übernommen aus der 3D-Druck Werkstatt:
- Schrift Bahnschrift bzw. Barlow, Zahlen und Nummern in JetBrains Mono
- kühle Grautöne (`#F3F5F6` Hintergrund, `#151C22` Text) und als Akzent das Werkstatt-Blau (`#2463A6`, wie „In Bearbeitung“ auf der 3D-Seite) statt Indigo. Die orange Variante zeigt `10-farbvergleich-…`
- Kopfleiste über die volle Breite mit dunklem Logo-Quadrat, Reiter mit blauem Unterstrich, kleine Symbol-Knöpfe
- Lehrkraft-Bereich: Reiter oben statt Seitenleiste
- große Seitentitel, Abschnittsüberschriften mit kräftigem Strich darunter, nummerierte Schritte (`01 02 03`)
- flache Karten (8 px Ecken, kein Schatten), dunkle Karte mit Raster für Countdown und Anmeldung
